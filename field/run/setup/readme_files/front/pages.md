````md
# 📄 Pages

Contiene las páginas principales que se usan como entradas de rutas (React Router).

## ✅ Buenas prácticas

- Cada archivo representa una ruta
- Nombrar en PascalCase: `Home.jsx`, `About.jsx`

## 📎 Ejemplo

```jsx
// src/pages/Home.jsx
export default function Home() {
  return <h1 className="text-2xl font-bold">Bienvenido a la Home</h1>;
}
```
````
